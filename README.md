# Recipe Prediction & Inverse Formulation Design

Plant-based cheese formulation tool: forward surrogate models predict physical
properties (pH, hardness, moisture, extensibility, gumminess, ...) from
ingredient composition + process parameters; an inverse optimiser designs
recipes that hit user-specified target values -- or match the measured profile
of a commercial cheese type ("archetypes": cheddar, mozzarella, gouda, ...).

```
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m jupyter nbconvert --to notebook --execute --inplace Recipe_Prediction.ipynb
```

Full execution takes ~60 min (model benchmark + two optimisation demos).
For interactive use: set targets in section 10, or `design_for("MOZZA")`
in section 11.

## Key design points

- Repeated GroupKFold on recipe fingerprints (719 unique recipes / 1204
  trials) -- duplicate recipes never straddle train/test.
- Noise ceiling per property from measurement replicates (ICC); model R2
  is judged against it.
- Hybrid featurisation: common-ingredient %s + category sums + ingredient
  spec features (physical state, nutrients) + process summaries.
- Inverse design: vectorised differential evolution, neighbour-seeded
  start population, sum-to-100% repair, top-K ingredient sparsity, and
  realism constraints (liquid-fraction band, per-category caps, pH band).
